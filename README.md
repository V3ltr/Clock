So this is my matrix clock. It must be connected to a power suply to run, i find my computer to be the best. It has a 8x32 matrix led display thats controlled by a separate controller, the main microcontroller is the esp32 DEVKITC. It has a alarm function:  you press the button one and then use the knob to set the time.l you turn left for hours and right for minutes. After setting the time you press the button to arm it. After it is armed you can press the button for the third time to cancel the alarm.
When the alarm finishes the screen flashes for 60s.
